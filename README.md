# Close Multiple Tabs

Close browser tabs above, below, or all other tabs with shortcut keys or the context menu. Supports Chrome and Edge.

"Above" means tabs before the current tab and "Below" means tabs after it, so the wording works for both horizontal and vertical tab layouts.

## Shortcuts

Configure shortcuts in your browser's extension shortcut settings:

```text
Chrome: chrome://extensions/shortcuts
Edge: edge://extensions/shortcuts
```

Default shortcuts (L/R are kept from earlier versions):

- `Alt+Shift+L`: Close Tabs Above
- `Alt+Shift+R`: Close Tabs Below
- `Alt+Shift+O`: Close Other Tabs

## Context menu

Right-click a page and choose **Close Tabs** → **Close Tabs Above** / **Close Tabs Below** / **Close Other Tabs**.

Pinned tabs are preserved.

# 关闭多个标签

通过快捷键或右键菜单关闭浏览器前面、后面或其它标签页。支持 Chrome 和 Edge。

“前面”指当前标签页之前的标签页，“后面”指当前标签页之后的标签页，横向和垂直标签页布局都适用。

## 快捷键

在浏览器扩展快捷键设置中配置快捷键：

```text
Chrome: chrome://extensions/shortcuts
Edge: edge://extensions/shortcuts
```

默认快捷键（L/R 沿用早期版本）：

- `Alt+Shift+L`：关闭前面标签页
- `Alt+Shift+R`：关闭后面标签页
- `Alt+Shift+O`：关闭其它标签页

## 右键菜单

在网页上右键，选择 **关闭标签页** → **关闭前面标签页** / **关闭后面标签页** / **关闭其它标签页**。

固定标签页会保留。
